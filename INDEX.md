## 💻 Command Reference

### Main Applications
```bash
# Best for demos
streamlit run streamlit_app_enhanced.py

# Automated presentation
python demo_presentation.py

# Show improvement metrics
python compare_systems.py

# Process all transactions (CLI)
python app_enhanced.py
```

### Testing & Verification
```bash
# Test that everything is installed
pip install -r requirements.txt

# Check Python version (need 3.8+)
python --version

# List all Tron files
ls -la D:/Tron/
```

## 🎨 What Each Application Shows

### streamlit_app_enhanced.py
- **Best for**: Interactive demos, exploration
- **Shows**: Risk visualization, metrics dashboard, learning progress
- **Use when**: Presenting to judges, answering questions

### demo_presentation.py
- **Best for**: Automated walkthroughs
- **Shows**: System learning step-by-step with commentary
- **Use when**: Need hands-free demo, explaining to non-technical audience

### compare_systems.py
- **Best for**: Proving value
- **Shows**: Static vs adaptive performance comparison
- **Use when**: Judges ask "why is learning better?"

### app_enhanced.py
- **Best for**: Processing all data
- **Shows**: All transactions with detailed output
- **Use when**: Testing, debugging, showing raw metrics

## 📊 Data Files Location

### Transaction Data
- `data/transactions.csv` - Original 12 transactions
- `data/transactions_enhanced.csv` - New 25 with fraud labels

### Generated Files (in storage/)
- `storage/user_profile.json` - Learned user profile
- `storage/transaction_history.json` - Processing history

### To Reset Everything
```bash
# Click "Reset Profile" and "Clear History" in Streamlit
# OR manually delete:
rm storage/user_profile.json
rm storage/transaction_history.json
```
